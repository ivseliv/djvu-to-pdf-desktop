# DjVu → PDF

Автономное приложение для перевода DjVu-книг в PDF. Оно переносит в PDF уже
существующий текстовый слой и оглавление из исходного DjVu — без OCR, облачных
сервисов или отправки файла куда-либо.

Проект основан на [dpsprep Кевина Крокера](https://github.com/kcroker/dpsprep)
и развивается как отдельная desktop-версия.

## Возможности

- Сохранение готового слоя для поиска, выделения и копирования текста.
- Перенос оглавления, если оно есть в исходном документе.
- Работа полностью на компьютере пользователя.
- Понятный интерфейс на русском: выбор файла, места сохранения и базовых
  параметров.
- Расширенный режим: тип страниц, JPEG-качество, число процессов, журнал и
  очистка временных заданий.
- Профили размера: сбалансированный 300 dpi, компактный серый, чёрно-белый и
  оригинальное разрешение. Уменьшение dpi не затрагивает текстовый слой.
- Параллельная обработка страниц, в том числе нативно на Apple Silicon.
- Ограниченная очередь страниц и потоковая сборка больших книг через QPDF.
- Восстановление прерванного задания без повторного хранения всех страниц.
- Полный прогресс: текст, страницы, блоки, объединение, проверка и сохранение.

## Установка

Приложение можно [запустить из исходников](#разработка-и-сборка).
Для Mac с процессором Apple Silicon доступна [инструкция по локальной сборке приложения](desktop/README.md#release-packaging).

| Платформа | Состояние |
| --- | --- |
| macOS Apple Silicon | Локальная сборка `.app` из исходников |
| macOS Intel | Планируется отдельная x86_64-сборка |
| Windows 10/11 x64 | Подготовлена сборочная основа; нужен native DjVuLibre wheel |
| Windows XP | Отдельный будущий legacy-проект, не та же сборка |

## Как это работает

1. Выберите `.djvu` или `.djv`.
2. Укажите имя готового PDF.
3. Оставьте включённым сохранение текстового слоя.
4. При необходимости откройте расширенные настройки и задайте количество
   процессов.
5. Нажмите «Конвертировать в PDF».

Если в DjVu изначально нет текстового слоя или оглавления, приложение не
создаёт их искусственно: OCR намеренно не используется.

Большая книга не собирается одним огромным объектом внутри Python. Страницы
сворачиваются в блоки по мере готовности, затем автономно объединяются
встроенным QPDF. Перед завершением приложение проверяет структуру PDF, число
страниц и присутствие перенесённого текстового слоя.

## Разработка и сборка

Для запуска из исходного кода нужны Python 3.11+ с Tk, DjVuLibre
(включая заголовки для сборки Python-модуля) и утилита `qpdf` в `PATH`:

```console
uv sync --no-dev
uv run dpsprep-gui
```

Подробности macOS-пакетирования: [desktop/README.md](desktop/README.md).
Контракт сборки Windows x64 и границы XP-поддержки:
[desktop/windows/README.md](desktop/windows/README.md).

Внутри также сохранён исходный CLI `dpsprep`; его документация и история
находятся в upstream-проекте.
